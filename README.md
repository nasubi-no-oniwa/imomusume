# 芋娘

教官の目を盗んで、60秒で芋を食べまくれ！ コンボ・芋祭り・階級・ランキングつきのブラウザゲーム。

- 遊ぶ：https://nasubi-no-oniwa.github.io/imomusume/
- 操作：「食べる」長押しで食べる／「敬礼」で敬礼（パソコンは J と F）
- 管理画面：admin.html（ランキングのあやしい記録を隠す）

## ファイル
- index.html：ゲーム本体（3Dモデル入り）
- config.js：Firebase の apiKey と databaseURL
- admin.html：管理画面
- database.rules.json：Firebase Realtime Database のルール

## 素材
- 3Dモデル・動き：Quaternius「Universal Base Characters」「Universal Animation Library」（CC0）
- BGM・効果音：ゲーム内で自作
